Put a failing type cast in the `ORDER BY` position so the value you want ends up in
the error message. The shape is:

`sort = CAST( <the value you want as text> || '' AS integer )`

Postgres will complain `invalid input syntax for type integer: "<value>"`. Use
`current_user` as the value, read it out of the error, and submit it to
`/solve?user=<value>`.
