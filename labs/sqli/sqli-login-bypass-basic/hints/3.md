You want the `WHERE` clause to match the `root` row and ignore the password
check entirely. Two primitives do this:

- close the string literal with a quote, then
- comment out the remainder of the line so the ` AND password='...'` part never
  runs.

So the shape of the username payload is: `<target-username>` + `'` + a SQL
line-comment. Put a real account name where `<target-username>` goes. Password
can be any junk. That is the whole trick.
