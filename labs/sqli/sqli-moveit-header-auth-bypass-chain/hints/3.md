```

```

Send it once to `POST /api/transfer/register`. Then present the token you chose as
the session cookie and download the file:

```
GET /files/download?path=confidential/flag.bin
Cookie: moveit_session=FORGED123
```

Finally, hash the downloaded bytes and submit the digest:

```
POST /solve   {"sha256":"<sha256 of the file>"}
```

The confidential file is unique to your container, so the hash you submit must be
of the file you actually downloaded. `/solve` returns `FLAG{...}` on a match.
