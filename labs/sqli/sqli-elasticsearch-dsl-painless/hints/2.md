Peek at the app's call:

```js
await es.search({ index: 'logs', ...body });
```

JavaScript's `{...body}` spread has **right-side precedence**. Whatever key the
caller puts in `body` overwrites the key that appeared before it. That includes
`index`.

There's an interesting-looking index in the cluster you probably shouldn't be
touching. Try to peek at what indices ES has (a `.cluster/state` call would work
if you had privileges — you don't). The name starts with a dot; a common
convention for "internal, hands-off" indices in ES.
