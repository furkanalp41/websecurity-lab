Start with the visible endpoint: `GET /metrics?category=web`. Put a single quote in
`category` and watch the response — a SQL error comes straight back. That confirms
`category` is concatenated into the query, and because rows are returned, this is a
**visible** injection: you can `UNION SELECT` your own columns out of it.

Count the columns first (`ORDER BY 3`, `ORDER BY 4`, ... or a `UNION SELECT 1,2,3`)
and get a feel for the types. You will use this endpoint to **read data back**.

But reading isn't the goal here — the interesting data isn't in a table at all.
Ask yourself: if a secret is _not_ in the database, where else could a database
process reach it, and what would you need to be able to _do_ (not just read) to get
at it?
