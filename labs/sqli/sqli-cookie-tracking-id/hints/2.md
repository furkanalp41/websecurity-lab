The `TrackingId` cookie is looked up in a database to choose your banner, and the
value is concatenated straight into the SQL — inside single quotes, roughly:

```
SELECT banner FROM banners WHERE trackingid = '<your cookie>'
```

Send `TrackingId=x'` (a single trailing quote) and watch the banner area: you
will get a personalisation error, because you have broken the string literal.
That is a live SQL injection in the cookie.

Now think about the shape of the query. It returns exactly **one** column. That
is the number that matters for the next step — if you want to graft your own
`SELECT` onto this one and have both halves line up, how many columns must _your_
`SELECT` return? And which SQL keyword lets you append a second result set whose
rows show up right next to the banner?

The database is SQLite, so `--` starts a comment that runs to the end of the line.
