Start by proving your input reaches the database. Change `category` between real
values (`jazz`, `rock`, `electronic`) and watch the result list change — so the
value is used in the query, not just displayed.

Now feed it something a normal category name would never contain: a single quote,
`?category=jazz'`. Read the response carefully. A clean "no results" page would
mean your input is being handled safely. A raw database error message means the
opposite: your quote broke the _syntax_ of a query the server built by pasting
your text into it. That error is not just noise — it is the server telling you
the shape of the statement you are sitting inside. What does the end of that
error message reveal about what comes _after_ your value?
