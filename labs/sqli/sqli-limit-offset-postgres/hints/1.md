Changing `page` shifts which rows you see, so your input is reaching the query —
and a non-numeric `page` (try `?page=abc`) makes Postgres complain right there on
the page. Notice _where_ your value lands: it is not inside a string literal, so
there is no quote to escape. It sits where a row **offset** goes. What kinds of
things, other than a plain number, is Postgres willing to accept in that slot?
