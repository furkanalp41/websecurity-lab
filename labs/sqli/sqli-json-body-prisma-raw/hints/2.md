Your value is concatenated straight into the SQL (that's `$queryRawUnsafe`, not
the safe tagged `$queryRaw`), so a single quote ends the string literal early and
the rest of your input is parsed as SQL. That means you can bolt on a `UNION
SELECT`.

Two things to get right for a UNION:

1. **Arity.** Count the columns the query already selects from `reports`. Your
   UNION half must select the same number.
2. **Types.** Each of your UNION columns must be compatible with the matching
   column above it. The confidential table you want is `audit_logs`, and its
   columns happen to line up nicely with what `reports` selects.

Verbose Postgres errors are returned — use them. A wrong column count or a type
mismatch will tell you precisely what to fix. Don't forget to deal with the
developer's trailing `'` after your injection point (SQL line comments help).
