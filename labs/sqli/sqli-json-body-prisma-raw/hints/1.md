A normal request works and even shows you the SQL it built:

```
POST /api/reports   {"filter":{"status":"open"}}
```

Look at exactly where your `status` value lands in that returned SQL string. It is
sitting inside single quotes: `WHERE status = '<your value>'`. Prisma is supposed
to be safe by default — but there are two very differently-named raw APIs, and
only one of them parameterises. What happens to the query if your `status` value
itself contains a single quote?
