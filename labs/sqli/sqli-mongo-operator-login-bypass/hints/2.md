# Hint 2

The bypass:

```json
{ "username": { "$ne": null }, "password": { "$ne": null } }
```

reads as "find a user whose username is not null and whose password is not null" —
which is every user, and `findOne` returns the first one (admin). You get a 200.

Now the important realisation: the server used your **entire body** as the query
filter. That means you are not limited to the `username` and `password` fields — you
can add _any_ field the document has and Mongo will filter on it too. The account
has a `reset_token` field. If you include it in the body, you can ask the database
questions about its value.

What operator lets you test whether a string **starts with** a given prefix? If a
matching prefix returns 200 and a non-matching prefix returns 401, you have a
yes/no oracle for each guess.
