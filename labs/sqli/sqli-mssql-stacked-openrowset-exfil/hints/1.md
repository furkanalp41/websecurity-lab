This is **MSSQL**, not MySQL or Oracle. MSSQL has a feature that neither
of those databases support in a single `execute()` call: **stacked queries**.

Try appending `'; SELECT 1; --` to the category parameter. If the endpoint
doesn't error, MSSQL executed both the original SELECT and your injected
statement as a batch. That means you can run INSERT, UPDATE, DELETE, or
even `EXEC sp_configure` as a side effect of the query.
