`GET /notices` reads from a `notices` table. You can INSERT into it via
stacked queries:

```
GET /assets?category=Laptops'; INSERT INTO notices(title,body) VALUES ('test','hello'); --
```

Then check `GET /notices` — your row should appear. Now the question is:
what table holds the secret, and what column? Think about what `POST /solve`
validates against. The table is called `secrets` and the column is
`mssql_secret`.
