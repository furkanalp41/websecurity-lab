`ORDER BY` accepts an expression, including a `CASE`. Order by `id` when some
condition is true and by `-id` when it is false, and the first row flips between
the lowest-id and the highest-id report:

```
sort = (CASE WHEN (<condition>) THEN reports.id ELSE -reports.id END) asc
```

First, learn the baseline: `?sort=id asc` tells you the lowest id, `?sort=id desc`
the highest. Now if the first row of your `CASE` payload equals the lowest id, your
`<condition>` was TRUE; if it equals the highest, it was FALSE. That is a one-bit
oracle you fully control — and `<condition>` can be any SQL boolean, including a
subquery against another table.
