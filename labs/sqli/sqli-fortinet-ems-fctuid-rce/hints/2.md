Postgres has a rarely-used form: `COPY <table> TO PROGRAM '<shell cmd>'` (and
`COPY <table> FROM PROGRAM '<shell cmd>'`). It is **superuser-only**. Here the
app's DB role IS a superuser (the misconfiguration this lab teaches), and the
sink runs with `psycopg2 .execute()`, which allows several `;`-separated
statements per call — so you can **stack** it after the audit insert.

Crucially, the _table-source_ form of `COPY ... TO PROGRAM` doesn't need any
`SELECT`. That is the intended bypass of the keyword IPS. Something like:

```
u', 'attacker-01', now()); COPY audit_log TO PROGRAM '<cmd>'; --
```

closes the base row, runs your command, and comments out the tail. Now: what
command should `<cmd>` be? The flag isn't in a table — it's a file on the DB
container. And you cannot reach the internet from the DB. But look at the compose
file. What is on the DB's network besides Postgres?
