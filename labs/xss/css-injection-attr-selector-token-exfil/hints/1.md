The staff preview renders **your** stylesheet (`POST /styles`), and its CSP is
`script-src 'none'` — so no JavaScript runs at all. A `<script>` or `<img onerror>`
is useless here. Stop reaching for JS.

But a stylesheet is not harmless. Look at what else is on `/preview`: a CSRF token
sitting in an `<input value="…">` **attribute**, next to the CSS you control. And
`img-src` is open. What can CSS do when it _matches_ something — can it make the
browser fetch a URL you choose? And can a CSS selector be made to match (or not
match) depending on what an attribute's value is?
