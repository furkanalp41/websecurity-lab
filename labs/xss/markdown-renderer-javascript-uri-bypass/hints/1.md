The only markdown WikiLite renders is the link: `[text](url)` becomes
`<a class="wiki-link" href="url">text</a>`. So your input lands in an **href**.

An `href` is an XSS sink even without any `<script>` or event handler: a link
whose href is `javascript:...` runs that script **when the link is clicked**. And
the admin reviewer here doesn't just _look_ at your page — the bot **clicks** the
primary link (`a.wiki-link`) to check where it goes. That click is your delivery.

So the whole task reduces to: get a `javascript:` scheme into that href. The
renderer's only defence is one line that removes the string `javascript:` from the
URL. Post a page with a `[text](url)` link and think about what that one strip
does — and doesn't — catch.
