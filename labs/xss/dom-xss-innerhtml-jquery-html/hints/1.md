Navigate to `/#<b>hi</b>` and watch the `#panel` div — your markup is rendered
as HTML, not shown as text. The dashboard's jQuery router does
`$('#panel').html(decodeURIComponent(location.hash.slice(1)))` on load and on
every `hashchange`, with no sanitisation.

The fragment never reaches the server, so this bug is entirely client-side (DOM
XSS). You need it to run in the admin's browser — the admin bot visits any path
you submit to `POST /report`, carrying its non-HttpOnly `session` cookie.
