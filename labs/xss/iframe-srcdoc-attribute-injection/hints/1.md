The server sanitizes every note with Bleach before storing it, so a bare
`<script>` is dropped. Post a couple of notes and read the JSON response — it
echoes back the stored, sanitized HTML, so you can see exactly what survived.

Now look at _which_ tags and attributes the allowlist keeps. Most are harmless
formatting (`<b>`, `<em>`, `<a href>`). But one entry stands out: `<iframe>` is
allowed, and on it the `srcdoc` attribute is allowed. Try posting

```html
<iframe srcdoc="hello"></iframe>
```

and confirm the iframe and its `srcdoc` come back intact. An allowlist checks
tag and attribute _names_ — it never inspects what an attribute's _value_ means.
What kind of value does `srcdoc` hold?

Also note: running script in _your own_ browser is useless here. Whose browser
holds the cookie worth stealing, and which page do they load?
