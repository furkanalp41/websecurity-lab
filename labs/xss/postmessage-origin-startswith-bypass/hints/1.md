View the page source. ChatCo embeds a chat-widget iframe (its URL comes from the
`?widget=` parameter) and registers a `window.addEventListener('message', …)`
handler. Two things in that handler matter: what it does with `e.data`, and how it
decides whether to trust the sender.

It writes `e.data` straight into the page with `innerHTML` — an XSS sink — but only
if the sender's **origin** passes a check. Read that check closely:

```js
if (e.origin.startsWith('http://widget-host')) { … }
```

`startsWith` is a **prefix** test with no delimiter. Which origins — other than the
real `http://widget-host:8080` — begin with the string `http://widget-host`?
