A relative URL like `main.js` is resolved against the document's **base URL**. The
`<base href>` tag changes that base URL for the whole page — and the CSP directive
that would forbid a `<base>` from doing so, `base-uri`, is **absent** here. Your
`?ref=` injection lands in `<head>` **above** `<script src="main.js">`, so an
injected `<base>` applies to it.

`script-src 'self'` still requires the script to be **same-origin**, so you cannot
point the base at another site. You do not need to: the app serves content **you**
control on its own origin. Upload a script:

```
POST /upload   {"js":"...your bundle..."}
      →  {"id":"<id>", "path":"/u/<id>/main.js"}
```

Now, if the page's relative `main.js` resolved to `/u/<id>/main.js`, it would load
your bundle — same-origin, so `script-src 'self'` allows it. What single tag,
injected before the `<script>`, makes `main.js` resolve under `/u/<id>/`?
