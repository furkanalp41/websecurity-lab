The `?ref=` value is reflected into `<head>` unescaped, so you have an HTML
injection — but the CSP is `script-src 'self'` with no `'unsafe-inline'`, so a
reflected `<script>` or `<img onerror>` will not run. Confirm that, then stop
trying to run inline script.

Read the CSP header carefully and think about what is **missing**, not just what
is present. `script-src 'self'` controls _where scripts may load from_. There is a
separate directive that controls how **relative** URLs on the page resolve — and
it is not in this policy.

Now view the page source: the app's bundle is loaded as `<script src="main.js">` —
a **relative** path. What decides where `main.js` actually points?
