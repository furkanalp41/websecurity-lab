View source at `/`. On load the page runs a little "scroll to section" helper:

```js
var t = decodeURIComponent(location.hash.slice(1));
if (t) {
  $(t);
}
```

The author meant `$("#billing")` — _select_ the section with that id. But think
about what jQuery's `$()` does with a **different** kind of string. What is the
difference between `$("#hi")` and `$("<b>hi</b>")`? One queries the document; the
other builds new elements from the string you gave it.

`t` comes straight from the URL fragment (`location.hash`) — something you fully
control. So you decide whether `$()` sees a selector or an HTML string.

Running a script in _your own_ browser gets you nothing, though. Whose browser
holds the cookie worth stealing, and what feature lets you hand that person a URL
(fragment and all)?
