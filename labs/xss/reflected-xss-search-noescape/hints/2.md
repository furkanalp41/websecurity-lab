`POST /report` (the "report a page to staff" feature) queues a same-site path
that the admin bot then visits — carrying its `session` cookie, which is **not**
`HttpOnly`, so `document.cookie` can read it.

So your plan is:

1. Put a `<script>` in `?q=` that reads `document.cookie`.
2. Send that value somewhere you can read it. The only listener reachable from
   the bot's network is the collector at `http://collector:9000/` (the DB/bot
   network has no internet route).
3. Submit that path via `POST /report` and wait for the bot.

How do you make a browser fire an HTTP GET to another host from inside a script,
without worrying about CORS? An image load (`new Image().src = ...`) does exactly
that.
