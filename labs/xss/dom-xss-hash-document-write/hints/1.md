Load the site with a fragment, e.g. `/#Alice`, and watch the greeting. Now try
`/#<b>Alice</b>` — your markup is written into the page, not shown as text. The
inline script does `document.write(... + decodeURIComponent(location.hash.slice(1)) + ...)`
with no sanitisation.

The fragment (`#…`) never reaches the server, so this bug lives entirely in the
browser (DOM-based XSS). You need the payload to run in someone's browser — the
admin bot visits any path you submit to `POST /report`.

What can the admin read that you can't? Look at `/flag.txt`.
